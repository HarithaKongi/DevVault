# DevVault

> A curated, community-driven index of developer tools, services, learning resources, APIs, and practical resources for building software.

DevVault is an open-source resource directory designed to help developers and students quickly discover useful tools without searching across dozens of websites.

## What You'll Find

- 🤖 AI and LLM tools
- 🔌 APIs and datasets
- 🗄️ Databases and backend services
- 🚀 Deployment and hosting platforms
- 🛠️ Developer tools
- 🎨 Design and UI resources
- 📚 Learning resources
- 🔐 Security resources
- 🧪 Testing and quality tools
- 🎓 Student developer resources

## Why DevVault?

The goal is simple: **make useful developer resources easier to discover, compare and share.**

Each entry should provide enough context to understand what a resource is useful for instead of becoming a directory of unexplained links.

## Contributing

DevVault is designed to grow through community contributions.

Before adding a resource, please read [CONTRIBUTING.md](CONTRIBUTING.md).

## Principles

- Prefer official and trustworthy sources.
- Keep descriptions short and factual.
- Avoid duplicate entries.
- Do not promote unsafe, deceptive or malicious services.
- Keep categories organized.
- Verify links before submitting changes.
