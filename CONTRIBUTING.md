# Contributing to DevVault

Thank you for helping improve DevVault.

## Adding a Resource

1. Choose the most appropriate category in `resources/`.
2. Check that the resource is not already listed.
3. Verify the official URL.
4. Add a short, factual description.
5. Keep the formatting consistent with the existing entries.
6. Open a pull request explaining what you added or changed.

## Entry Format

Use this format:

| Resource | Free Tier | Best For | Link |
|---|---|---|---|
| Example | Yes | Short description | [Visit](https://example.com) |

Do not add affiliate links, tracking links, referral links, or misleading URLs.

## Quality Guidelines

- Prefer official websites and documentation.
- Do not submit duplicate resources.
- Avoid unsupported claims.
- Keep descriptions concise.
- Report broken links through an issue or pull request.
- Keep entries relevant to developers or students.

## Pull Requests

Please use a clear title and explain:

- What was added or changed
- Why it belongs in DevVault
- Any relevant verification performed

Small, focused pull requests are preferred.
